## Cloudflare failure diagnosis — 2026-10-21

The reported `phoenix_reffaella` failure was reproduced with an anonymous request to the same endpoint: HTTP 403, `Content-Type: text/html; charset=UTF-8`, `server: cloudflare`, and `cf-mitigated: challenge`. This is a website-verification response, not a Tag lookup result or evidence of an incorrect API Key. No user credentials were read for this diagnosis.

The adapter now recognizes website-verification headers separately from 401 authentication failure and ordinary 403 access denial; successful responses must identify JSON. The dialog preserves input, wraps the full error within its fixed width, and offers a credential-free browser check link. Browser verification remains user-operated and does not grant the app its session or guarantee API access.
