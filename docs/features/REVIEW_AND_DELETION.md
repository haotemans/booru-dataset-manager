# Review and deletion

Image review and similarity review are separate. Grid and large-image views show source, artist/character, tags, caption and similarity candidates. States: pending, keep, unsatisfactory, needs review; ratings 1–5; quality flags include blurry, low resolution, compression, composition and content mismatch.

Batch operations cover state, rating, associations, tags, delete-candidate queue and export exclusion. Keyboard plan: arrows navigate, 1 unsatisfactory, 2 pending, 3 keep, Space select, Ctrl+A select filtered, Delete queues candidates only.

Unsatisfactory excludes from export by default but does not delete the file. Deletion requires candidate list, impact preview and explicit confirmation; prefer quarantine/recycle. Removing artist/character association does not delete media; removing one source record does not delete shared media; deleting one file does not delete its whole visual identity group.
