# Product scope

Booru Dataset Manager is a Windows-first desktop tool for collecting, organizing, reviewing, optimizing, exporting, and backing up image-training datasets.

In scope: Danbooru, Gelbooru, Pixiv, X/Twitter and E-Hentai adapters subject to supported authentication and provider policy; original-dimension gating (minimum 800×800); MD5 exact duplicate detection and SHA-256 integrity; DINOv3 embeddings and human-reviewable identity matching; artist/character libraries and protected domain-tag semantics; independent raw-tag, optimized-tag and caption sidecars; review, quality flags, reusable export profiles, dashboard coverage statistics, and manual ModelScope backup/restore.

Constraints: no CAPTCHA/paywall/access-control bypass; no silent raw-tag or human-reviewed text rewrite; no AI image upload without explicit opt-in; no plaintext credentials in source or backup; no claim of provider, DINOv3, Windows or ModelScope support before real integration verification.

Completion requires implemented workflows, tested failure recovery, platform verification, and status evidence for every verified claim.
